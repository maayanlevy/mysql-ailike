# Example output

These images are plain HTML renderings of the adjacent `.txt` transcripts,
captured from the MySQL client against the project's isolated demo database.
They are not screenshots of a native Terminal window.

Prompts, SQL, results, warnings, and timings come from the client output.
Only terminal control sequences, line endings, and trailing whitespace were
normalized. The window
frame is illustrative. Timings describe those runs, not a performance guarantee.

The film and JOIN examples use MySQL's `\G` terminator to display rows vertically.
The copyable README queries use `;` and return the same columns and rows in a table.
